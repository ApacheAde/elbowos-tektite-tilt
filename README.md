# Tektite Tilt

Full-colour Python 3 neon marble-labyrinth arcade for [ElbowOS](https://x.com/ElbowOS).

Tilt a crater board so a molten tektite marble rolls toward gem motes.
Green bumpers kick the shot. Dark pits swallow the stone.

WASD or arrow keys tilt.
R resets.

## Play

```bash
pip install -r requirements.txt
python3 tektite_tilt.py --play
```

## Record a 9:16 reel

```bash
python3 tektite_tilt.py --record
```

Writes a 1080x1920 h264 clip (15s @ 30fps) with title, score, and `x.com/ElbowOS` burned into the frames.
